# licenses/

Third-party asset attributions for the packaged shell (plan §7). See `NOTICE`.

Status: the Roboto / Roboto Flex TTFs and any Material Symbols-derived icons are **not yet
vendored** (text currently falls back to a generic sans). When they are added under
`../assets/`, drop the upstream Apache-2.0 `LICENSE` text here and the packaging step (M9)
installs this dir to the package's doc path.

# arstro-shell API

Generated by `arstro-shell-cc api`. Do not edit: a test regenerates and compares it.

Lengths are dp. One command per line; a value with a space is written `key="two words"`.

## Commands

| Command | Arguments | What it does |
|---|---|---|
| `app launch` | `<app-id>` | Bring the app to the front, starting it if it is not running. |
| `app close` | `<task>` | End a task and remove it from recents. |
| `apps rescan` |  | Read the installed bundles again. |
| `nav home` |  | Go to the home screen. |
| `nav back` |  | Back: closes the shade, leaves recents, or asks the front app. |
| `nav recents` |  | Show the recent apps. |
| `task focus` | `<task>` | Bring a running task to the front. |
| `task connected` | `<task>` | Host: the task's process attached to the app socket. |
| `task exited` | `<task>` | Host: the task's process is gone. |
| `task back-unhandled` | `<task>` | Host: the app did not use Back, so the shell goes home. |
| `shade open` |  | Pull the quick-settings and notification shade down. |
| `shade close` |  | Push the shade up. |
| `shade toggle` |  | Open the shade if closed, close it if open. |
| `set` | `<key>=<value> ...` | Change settings. Keys and ranges: see settings. |
| `notify post` | `title=<text> [body=<text>] [app=<app-id>]` | Post a notification. |
| `notify dismiss` | `<id>` | Remove one notification. |
| `notify clear` |  | Remove every notification. |
| `touch` | `down|move|up|cancel <x> <y> <time-ms>` | One touch sample in dp. Drives the system gestures. |
| `screen` | `<width> <height>` | The screen size in dp. |

## Events

| Event | Fields | When |
|---|---|---|
| `nav.changed` | `state=home|app|recents task=<n>` | The front of the screen changed. |
| `task.spawn` | `task=<n> app=<app-id>` | The host must start this app's process. |
| `task.state` | `task=<n> state=starting|running|paused` | A task's lifecycle state changed. |
| `task.back` | `task=<n>` | The host must ask this app to handle Back. |
| `task.kill` | `task=<n>` | The host must end this task's process. |
| `task.closed` | `task=<n> app=<app-id>` | A task left the recents list. |
| `shade.changed` | `open=true|false` | The shade opened or closed. |
| `gesture.begin` | `kind=home|back|shade-open|shade-close` | A touch was claimed by the system. |
| `gesture.end` | `kind=<kind> result=cancelled|home|recents|back|shade-opened|shade-closed` | The system gesture finished. |
| `setting.changed` | `key=<key> value=<value>` | A setting has a new value. |
| `notify.posted` | `id=<n> app=<app-id> title=<text>` | A notification arrived. |
| `notify.dismissed` | `id=<n>` | A notification was removed. |
| `apps.changed` | `count=<n>` | The list of installed apps was read again. |
| `screen.changed` | `w=<dp> h=<dp>` | The screen size changed. |
| `error` | `message=<text>` | A command was rejected. Also kept in lastError. |

## Settings

| Key | Type | Default | Range | Meaning |
|---|---|---|---|---|
| `brightness` | number | `1` | 0.05 to 1 | Screen brightness. |
| `volume` | number | `0.6` | 0 to 1 | Media volume. |
| `wifi` | bool | `true` |  | Wi-Fi radio. |
| `bluetooth` | bool | `false` |  | Bluetooth radio. |
| `dnd` | bool | `false` |  | Do not disturb: notifications arrive silently. |
| `reduced-motion` | bool | `false` |  | Replace movement with short fades. |
| `clock24` | bool | `true` |  | 24-hour clock. |
| `scale` | number | `1` | 0.75 to 2 | Size of everything on screen, on top of the display's own density. |
| `accent` | color | `#4F7EF7` |  | The one accent colour, #RRGGBB. |
| `device-name` | text | `Arstro` |  | The name of this device. |

## System gestures

| Threshold | Value |
|---|---|
| Bottom edge zone (Home, Recents) | 24 dp |
| Side edge zone (Back, inside an app) | 20 dp |
| Top edge zone (shade) | 32 dp |
| Zone that closes an open shade | bottom 72 dp |
| Travel before the system claims the touch | 10 dp |
| Sideways travel that means Back | 56 dp |
| Upward speed that means Home | 700 dp/s |
| Height that means Recents when released slowly | 0.12 of the screen |
| Height that means Home at any speed | 0.45 of the screen |

## State dump

`arstro-shell-cc state` prints one line per fact: `screen`, `nav`, `shade`, `app`, `task`, `notification`, `setting`, `error`. The revision counter and a gesture in flight are left out, so two dumps of the same state are identical.
